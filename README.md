# Santa Madre — Meu Futuro Profissional

Aplicativo Android para experimentar quatro figurinos virtuais: Escritor, Advogado, Médico e Empresário.

## APK

Acesse **Actions → Gerar APK Android → Run workflow**. Ao final, baixe o artefato **SantaMadre-APK**, extraia e instale `app-debug.apk` no Android.

O aplicativo usa a câmera e desenha uma roupa ilustrada sobre o tronco. Requer internet para carregar o rastreamento MediaPipe. Protótipo para testes.
